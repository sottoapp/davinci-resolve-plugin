# Docs

This repository holds code and the skills' operating instructions. Research, design decisions, test evidence, the publishing checklist, the backlog and the Gemini video analyses live in the private Notion workspace page **DaVinci Resolve Context**. Skills name it as their source; they do not need to read it to work.

Kept here:
- [skill-library.md](skill-library.md): every skill, grouped by layer (generated by `scripts/gen_skill_library.py`; CI fails if it is stale).
- [session-handoff.md](session-handoff.md): the SessionEnd/SessionStart hooks and the `scripts/handoff.mjs` CLI.

## Rules the validator enforces (`python3 scripts/validate_plugin.py`)
1. **Layout:** `plugin/` is what installs (at most 512 files, each non-image file at most 256 KiB); `plugin-advanced/` is the optional offline server add-on; `vendor/davinci-resolve-mcp/` is verbatim upstream and is not shipped; `evals/` holds behaviour and trigger cases.
2. **Skill names are flat; the prefix is the layer:** `resolve-guide-*` (Resolve itself), `editing-*` (craft), `resolve-*` / `house-style` (driving the MCP), `realestate-*` / `wedding-*` / `event-*` (verticals), `authoring-resolve-skills` (meta).
3. **Descriptions** start "Use when", state triggers only, third person, at most 500 characters (1024 hard).
4. **Context budget** (estimated tokens = chars / 4): all skill listings at most 4,500; a `SKILL.md` body warns above 1,000 and fails above 1,500. Put per-action tables in `references/`.
5. **Versions:** the plugin version lives only in `plugin/.claude-plugin/plugin.json`; the launcher pins one exact upstream npm version, equal to `vendor/davinci-resolve-mcp/package.json`; `plugin-advanced/scripts/launch-mcp.mjs` is an identical copy of `plugin/scripts/launch-mcp.mjs`.
6. **Hooks:** plain `node` commands; PreToolUse guards set `onFailure: block`; no `bin/` folder.

Before committing (from the repository root):
`python3 scripts/validate_plugin.py && node --test plugin/hooks/test/guards.test.mjs plugin/hooks/test/handoff.test.mjs && claude plugin validate plugin && claude plugin validate plugin-advanced && claude plugin validate .`
