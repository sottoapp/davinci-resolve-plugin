# Real-estate editing workflow — digest

One 16:9 master edit feeds shorter deliverables; build native 9:16/1:1 timelines instead of shrinking. Order: brief → ingest/cull → story assembly in room order →
music/VO → tighten to musical phrases → B-roll, transitions, speed changes → colour match → audio → titles/lower thirds/logo/CTA → QC → platform variants.

| Deliverable | Length | Notes |
|---|---|---|
| Listing video | 45–90 s | hook with strongest feature; hero shots 3–5 s, wides 2–4 s, details 1–2.5 s; ~15–30 shots |
| Cinematic walkthrough | 2–4 min (up to 5) | holds 4–10 s; fewer cuts; arrival → hero interior → lifestyle → craft → private → amenities → outdoor → close |
| Agent intro | 30–60 s social, 60–90 s site | agent on camera in first 3 s; J-cuts; consistent lower third; captions |
| Drone feature | 15–30 s insert, 30–60 s social | shots 3–6 s in edit, capture 5–10 s moves; match altitude/horizon |
| Twilight | 15–30 s insert | real twilight window 20–30 min; match day grade; avoid fake skies |
| Social vertical | 15–60 s | best room in first 1–2 s, not a logo; reframe each shot manually; captions |
| Neighborhood/lifestyle | 60–90 s (to 2–3 min) | location-specific proof; no unverified claims about schools/crime/walkability |

Pacing/transitions: straight cuts by default; speed ramps only to shorten travel or emphasise a reveal; avoid zoom-transition packs; selective stabilisation (warped
architecture is worse than natural movement). Music: instrumental, licensed; 80–100 BPM calm/luxury, 110–140 modern/social; cut to phrases; duck 3–6 dB under VO.
Batch: master template project, Power Bins, duplicate per property, queue all variants; typical turnaround 24–72 h. Mistakes: weak open, equal time per room, long
walking footage, effect overuse, one generic master, stale facts, mismatched WB/exposure, music over VO, no captions, unlicensed music, over-stabilising, no QC of the rendered file.
