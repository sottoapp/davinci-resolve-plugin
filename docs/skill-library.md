# Skill library

Generated by `scripts/gen_skill_library.py` from `skills/*/SKILL.md` — do not edit by hand.

**New** = authored in this repo from `docs/research/`; **Upstream** = ported from `samuelgursky/davinci-resolve-mcp` (see `UPSTREAM.md`).

How the layers fit: the *guide* and *craft* skills know Resolve and editing; the *MCP* skills know how to drive it. Guide skills say what the scripting API cannot do and give the manual UI steps instead.
