# Shortcuts (Resolve defaults — verify in Keyboard Customization) and mistakes

| Operation | Key | Operation | Key |
|---|---|---|---|
| Cut / Edit page | Shift-3 / Shift-4 | Mark In / Out | I / O |
| Play rev / stop / fwd | J / K / L | Mark clip / clear In-Out | X / Opt-X |
| Go to In / Out | Shift-I / Shift-O | Add / modify marker | M / Shift-M |
| Selection / Trim / Dynamic Trim | A / T / W | Blade / split at playhead | B / Cmd-Ctrl-B (or \) |
| Snapping | N | Enable/disable clip | D |
| Match frame | F | Source Tape (Cut / Edit 20+) | Q / Shift-Q |
| Insert / Overwrite / Replace / On Top | F9 / F10 / F11 / F12 | Fit to Fill / Append | Shift-F11 / Shift-F12 |
| Ripple delete | Shift-Delete | Ripple edit left / right | Cmd-Ctrl-Shift-[ / ] |
| Default transition | Cmd-Ctrl-T | Retime controls | Cmd-Ctrl-R |
| Trim start/end to playhead | Shift-[ / Shift-] | Nudge 1 frame | , / . |
| Zoom timeline to fit | Shift-Z | Undo / redo | Cmd-Ctrl-Z / +Shift |

Remove silence (shown in a Resolve 20 beginner tutorial; edition availability not confirmed): select clip ▸ **Clip ▸ Audio Operations ▸
Ripple Delete Silence…** — set threshold (default −25 dB) and minimums, then **Remove**. Always listen
afterwards; intentional pauses are editorial. Digital punch-in for jump-cut variety: Inspector ▸ Video
▸ Transform ▸ Zoom + Position.

## Common mistakes
1 Editing to the wrong track. 2 Insert vs Overwrite confusion. 3 Delete (leaves a gap) vs Ripple Delete.
4 Ignoring Sync Lock (music/B-roll drift). 5 Linked Selection off by accident (video/audio split).
6 Transition without handles. 7 Trimming the wrong edge. 8 Forgetting Dynamic Trim is active (JKL trims).
9 Retiming without checking audio. 10 Overusing compound clips (shared container). 11 Effects on every
clip instead of one adjustment clip. 12 Treating Source Tape as a replacement for bin organization.
13 Assuming Cut and Edit shortcuts match. 14 Judging uncached interpolated effects. 15 Not verifying
frame rate/timeline settings first.
