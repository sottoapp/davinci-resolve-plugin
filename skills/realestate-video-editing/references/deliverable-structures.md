# Deliverable structures (conventions from practitioner guides — adjust to the property)

Typical overlays: opening "Just Listed"/feature; lower third (price · beds · baths · address); feature callouts; closing agent name, brokerage, phone, URL, CTA.
Keep one font, colour, logo position and animation across all deliverables. **Branded text belongs only in branded cuts** (see `realestate-delivery-compliance`).

## Listing video (45–90 s, ~15–30 shots)
Hook (0–3 s strongest feature) → exterior → entry → living/dining → kitchen → primary bedroom → secondary bedrooms/baths (brief) → feature spaces → outdoor → close
(exterior/twilight/aerial pull-away + address + CTA). Music 80–100 BPM calm/luxury, 110–140 modern.

## Cinematic walkthrough (2–4 min)
Cold open → aerial/wide context → arrival → hero interior → lifestyle flow (living→dining→kitchen, continuous gimbal) → craftsmanship montage (hardware, millwork, textures) →
private spaces → amenities → outdoor lifestyle → closing (twilight/aerial pull-out/end card). Holds 4–7 s (hero 6–10 s), fewer cuts than social; match cuts, J/L cuts and sound bridges over effects.
Keep camera height, horizon and direction consistent.

## Agent introduction (30–60 s social, 60–90 s site)
On camera / lifestyle hook → name, market, role → differentiator → proof (result, process, testimonial fragment) → B-roll → CTA. Remove dead air; J-cut the voice over B-roll; keep the agent visible;
consistent lower third; caption everything. Mistake: a generic property montage with the agent appearing only at the end.

## Drone / aerial (15–30 s insert; 30–60 s dedicated; ~90–120 s only if land/view sells)
Context → approach → rise over roofline → orbit/lateral → top-down lot/pool/acreage → relation to water/parks/amenities → pull-away. Shots 3–6 s in the edit (capture 5–10 s moves).
Cut on direction of movement; match altitude and horizon; don't stack similar orbits; label off-property views accurately.

## Twilight (15–30 s insert, 30–60 s social)
Day exterior or dusk transition → front elevation with lights on → glowing living room through windows → patio/pool/fire pit → blue-hour aerial or locked-off exterior → address/CTA.
Real twilight is a 20–30 min window; match the daytime grade; avoid halos, over-blue skies, clipped practicals and obviously artificial skies.

## Social vertical (15–60 s)
Best room 1–2 s → kitchen/hero living → 1–2 details → primary/bath → outdoor/view → price/address/CTA. Reframe manually; keep text in the centre-safe region; burned-in captions; separate vertical title template;
film a native vertical pass of the best rooms when possible.

## Neighborhood / lifestyle (60–90 s, to 2–3 min)
Hook → establishing street/landmark → local businesses/community → park/trail/waterfront/commute → property connection → agent insight → CTA. Location-specific footage with clean ambience; no identifiable people without
permission; no unverified claims (schools, crime, commute, "walkability") — have the agent approve factual copy.
